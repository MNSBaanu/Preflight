> [!summary] Summary
> Preflight is the step before the IDE. Instead of turning a prompt straight into code, it walks you through the plan, the file/module structure, and the decisions (with reasoning) behind an implementation — so you understand what you're building before you open an editor. Currently in concept stage; the codebase is an unmodified `create-next-app` scaffold.

## How it works
Nothing is implemented yet. The repo is currently the stock `create-next-app` output (Tailwind + TypeScript template) with no custom pages, components, or logic beyond the default scaffold. The product concept (README.md) is settled: given a build request, Preflight should produce a plan, a proposed file/module structure, and the key decisions/trade-offs behind that structure — before any code is generated. The exact shape of that output (UI, data model, how "decisions" are captured/navigated) has not been designed yet.
